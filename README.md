Entry for [Name the Robot Band](https://make.fun/c/u-motasimfuad-name-the-robot-band-1ffc6a74) on make.fun: one funny name for a band made of robots, plus a few words on its hit song, all under 200 characters.

## The entry

> Ctrl+Alt+Defeat — hit single 'Have You Tried Turning Me Off and On Again?'

74 characters. The band name is a keyboard shortcut with a losing streak, and the hit song is the one line every robot (and every IT helpdesk) has heard a thousand times — a breakup ballad you can fix by rebooting.

## How it works

`main.py` writes the entry, exactly as written, to `/output/entry.txt` (UTF-8, one line, no trailing newline), after validating it against the competition gate: 1–200 characters, not only white space, single line.

```sh
python3 main.py
```
